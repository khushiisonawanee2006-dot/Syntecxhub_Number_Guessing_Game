# Syntecxhub_Number_Guessing_Game

A Python-based Number Guessing Game where players guess a randomly generated number with hints.

## Features:
- Easy, Medium, and Hard difficulty levels
- Random number generation
- Higher/Lower hints
- Replay option
- Best score tracking
- Input validation

## Technologies Used:
- Python
- Random Module

## Internship Project
Created as part of Syntecxhub internship task.
